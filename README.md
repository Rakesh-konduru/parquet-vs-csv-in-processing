# parquet-vs-csv-in-processing
To show the difference in the processing of data in csv and parquet data .
Parquet data refers to data format that processes the data in coloum wise.
unlike csv parquet data is not processes row by row
insted it process the data column by column for easy process.
if a csv file is converted to parquet format you will be all the data in file is converted in unredable form link a binary code.
#ADVANTAGES OF PARQUET DATA:
easy analysis,
fast data processing,
easy to extract data ,
easily calculate max,min,avg,differnces  etc..
column  wise data extraction,
#OBSERVATION:
when we convert the csv data into in parquet form the size of the file reduces.
